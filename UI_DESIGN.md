# SkillMate UI/UX Design Documentation

## 🎨 Design System

### Color Palette
- **Primary Background:** #454040
- **Secondary Background (Cards):** #605B51
- **Accent Color (Buttons, Links):** #D8D365
- **Highlight Color (Hover, Active):** #E6F082
- **Text Color:** #FFFFFF / #E0E0E0
- **Muted Text:** #B0B0B0
- **Border/Divider:** rgba(216, 211, 101, 0.1-0.2)

### Typography
- **Font Family:** 'Inter', 'Roboto', 'Helvetica', 'Arial', sans-serif
- **Headings:** Bold (600-800 weight)
- **Body:** Regular (400 weight)
- **Buttons:** Medium (500-600 weight)

### Spacing & Layout
- **Border Radius:** 10px-25px (rounded corners)
- **Card Radius:** 15px
- **Button Radius:** 25px (pill-shaped)
- **Shadows:** 0 4px 20px rgba(0, 0, 0, 0.3)
- **Hover Shadows:** 0 8px 30px rgba(0, 0, 0, 0.4)

### Animations
- **Transition Duration:** 0.3s ease
- **Hover Effects:** 
  - Background color change
  - Transform: translateY(-2px to -8px)
  - Box shadow enhancement

## 📱 Components

- Lift effect on hover

### 4. Text Fields
- Background: #605B51

### 5. Avatars
- Circular
- Background: #D8D365

## 🎯 Design Principles

1. **Consistency:** Same color palette and spacing throughout
2. **Clarity:** Clear visual hierarchy with typography
3. **Feedback:** Hover states and loading indicators
4. **Accessibility:** Good contrast ratios
5. **Modern:** Rounded corners, shadows, gradients
6. **Responsive:** Mobile-friendly layouts
7. **Performance:** Smooth animations (0.3s)
